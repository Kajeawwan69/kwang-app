# 🪲 KWANG (by ZOOTRONIA)

**Global Beetle Community & Marketplace**
*Born from Thailand. Built for Beetle Keepers Worldwide.*

RAISE • RECORD • BREED • TRADE • CONNECT

สมุดบันทึกฟาร์มด้วงสำหรับผู้เลี้ยง — ใช้ได้ทั้งมือถือและคอมพิวเตอร์ เป็นทั้งเว็บและแอปติดตั้งได้ (PWA)

## ฟีเจอร์ (เฟส 1)

- **บันทึกด้วง** — รหัส/ชื่อ, สายพันธุ์, เพศ, ระยะ (ไข่ → L1/L2/L3 → ดักแด้ → ตัวเต็มวัย), น้ำหนัก, ขนาด, ภาชนะ/ชั้นวาง, ที่มา, วันที่, สายเลือด, รูปถ่าย, โน้ต
- **ด้วงของฉัน** — รายการทั้งหมด ค้นหา + กรองตามระยะ เปิดดูรายตัวพร้อมไทม์ไลน์การเลี้ยง
- **ภาพรวม** — นับจำนวนตามระยะ/สายพันธุ์, การ์ด "ต้องดูแลวันนี้" (เปลี่ยนดิน/เยลลี่/ชั่งน้ำหนัก คำนวณจากรอบเวลาอัตโนมัติ), อุณหภูมิ+ความชื้นจากตำแหน่งผู้ใช้เทียบช่วงที่เหมาะกับด้วง (20–28°C, 60–80%)
- **Beetle World** — สถิติส่วนตัว (หนอนน้ำหนักดีสุด, ตัวเต็มวัยใหญ่สุด) + ตัวอย่างฟีดชุมชน (ระบบออนไลน์จริงคือเฟส 2)
- **สำรอง/กู้ข้อมูล** — export/import เป็นไฟล์ JSON
- **ทำงานออฟไลน์ได้** — ข้อมูลเก็บในเครื่อง (IndexedDB) + service worker แคชตัวแอป

## โครงสร้างไฟล์

```
index.html            หน้าแรกสาธารณะ (landing page, ไทย+อังกฤษ)
app.html              ตัวแอป (SPA)
css/app.css           ธีมเขียวป่า + ทองเปลือกด้วง (ตามดีไซน์ canvas)
js/db.js              ตัวจัดการฐานข้อมูลในเครื่อง (IndexedDB)
js/app.js             ลอจิกทุกหน้า (router + views)
manifest.webmanifest  ทำให้ติดตั้งเป็นแอปได้
sw.js                 service worker (ออฟไลน์)
icons/                ไอคอนแอป
```

## รันทดสอบในเครื่อง

```
python -m http.server 8123
```

แล้วเปิด http://localhost:8123 (เปิดจากไฟล์ตรง ๆ ไม่ได้ เพราะ service worker ต้องการ http)

## เอาขึ้นอินเทอร์เน็ตฟรี (แนะนำ: Cloudflare Pages)

1. สมัคร https://dash.cloudflare.com (ฟรี ไม่ต้องใช้บัตรเครดิต)
2. เมนู **Workers & Pages → Create → Pages → Upload assets**
3. ตั้งชื่อโปรเจกต์ เช่น `zootronia` แล้วลากไฟล์ทั้งโฟลเดอร์นี้ไปวาง (ยกเว้นโฟลเดอร์ `.claude`)
4. กด Deploy — ได้ URL ฟรีทันที: `https://zootronia.pages.dev` พร้อม HTTPS
5. อัปเดตแอปครั้งถัดไป: เข้าโปรเจกต์เดิม → Create new deployment → ลากไฟล์ใหม่

ทางเลือกอื่นที่ฟรีเหมือนกัน: GitHub Pages, Netlify Drop (https://app.netlify.com/drop ลากวางได้เลยไม่ต้องสมัครตอนทดลอง)

### จดโดเมนจริงทีหลัง

พอแอปติดตลาด ค่อยซื้อโดเมน (เช่น zootronia.com ปีละ ~350–600 บาท ซื้อผ่าน Cloudflare ได้เลย) แล้วผูกกับ Pages ในเมนู **Custom domains** — ผู้ใช้เดิมไม่กระทบ

## ติดตั้งเป็นแอป

- **Android (Chrome):** เปิดเว็บ → เมนู ⋮ → "เพิ่มไปยังหน้าจอหลัก" / "ติดตั้งแอป"
- **iPhone (Safari):** ปุ่มแชร์ → "เพิ่มลงในหน้าจอโฮม"
- **Windows/Mac (Chrome/Edge):** ไอคอนติดตั้ง ⊕ ที่ปลายแถบที่อยู่

## แผนเฟส 2 (ชุมชนออนไลน์)

ต้องมีฝั่งเซิร์ฟเวอร์สำหรับบัญชีผู้ใช้ + ฟีด + ตารางแข่ง แนะนำ **Supabase** (ฟรี, PostgreSQL + ระบบล็อกอินสำเร็จรูป):

- สมัครสมาชิก/ล็อกอิน (อีเมลหรือ Google)
- ซิงก์ข้อมูลด้วงข้ามอุปกรณ์
- ฟีดโพสต์เทคนิค + รูป
- ตารางแข่งสถิติ (น้ำหนักหนอน L3 / ขนาดตัวเต็มวัย) แยกตามสายพันธุ์ + ปุ่มส่งผลเข้าแข่ง

## ข้อควรรู้

- เฟส 1 ข้อมูลอยู่ในเครื่อง/เบราว์เซอร์ที่ใช้เท่านั้น — ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลหาย ให้กด **ตั้งค่า → สำรองข้อมูล** เก็บไฟล์ไว้เป็นระยะ
- ข้อมูลอากาศดึงจาก open-meteo.com (ฟรี ไม่ต้องมี key) — เป็นอากาศภายนอกตามตำแหน่ง ไม่ใช่ในห้องเลี้ยง
